Pour compiler et exécuter le programme, il faut être connecté au réseau de l'IUT ou à Edu-VPN.
Il suffit ensuite de lancer Main.kt pour exécuter le programme.
Les settings (gradle.properties, build.gradle.kts, settings.gradle.kts) qui sont donnés dans le dépot sont fait pour fonctionner sur les PC de l'IUT.

Usage de l'IA:
La plupart des styles (ex: boutonSuppr.style = "-fx-font-family: 'Inter'; -fx-font-size: 14px; -fx-font-weight: bold; -fx-background-color: #E57373; -fx-text-fill: white; -fx-background-radius: 50; -fx-border-radius: 50; -fx-border-color: black; -fx-border-width: 2px; -fx-cursor: hand;") on été fait avec l'aide de Gemini/Claude, en donnant en prompt ce que l'on avait fait sur Figma.

Le fichier OutilsAffichageCartes.kt à été généré avec l'aide de l'IA, il permet de découper une image qui contient toutes les cartes en cartes individuelles.

Pour la vue des règles, l'IA (Claude) à été utilisé pour copier les règles du jeu.

L'IA (Claude) a été utilisé pour le modèle ainsi que le controlleur du menu d'initialisation de la partie, notamment pour le système d'index utilisant userData dans la vue, et ajouterJoueur qui renvoie l'index ou le joueur à été ajouté
